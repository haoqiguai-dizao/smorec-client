# 局部镜头片段

`Project.compositions` 是可选的源时间片段数组，按开始时间排序、互不重叠。每段使用半开区间 `[start, end)`，相邻边界立即归下一段；段外完全恢复原来的桌面缩放、摄像头布局／可见性和录制 presenter 模式。旧项目没有此字段时不增加任何默认片段。

`screen` 独立选择 `recording`、`hidden` 或 `background`。隐藏及替换均不绘制桌面源、鼠标或点击高亮，不依赖摄像头素材是否可用。替换支持现有 `BACKGROUNDS` 预设和项目拥有的 `asset:<id>`；图片由主进程授权、调用方加载，作为 `renderFrame` 最后一个参数传入。缺失图片使用中性底色，绝不回退到桌面内容。

`camera.x/y` 是相对输出画布的左上角坐标，不是原片坐标，也不是旧 `WebcamStyle.placement` 的中心坐标。`size` 沿用宽度除以画布短边的定义，编辑范围为 0.08～2，形状几何约束会将画面完整钳制到画布内。`compositionCameraMaxSize` 提供形状及输出比例对应的实际滑杆上限。这些范围仅用于编辑片段，不改录制浮窗 12%～42% 的限制。

`camera.zoom` 是可选的 1～3 倍居中数字变焦，只覆盖所选片段；缺省沿用当前源时间的录制变焦。它不修改人物框几何。新建片段默认不冻结变焦轨迹；复制或分割已有显式覆盖时保留该值。

片段内的显式大小不再随桌面缩放自动变小。可见性、形状和镜像分别覆盖当前源时间的摄像头布局，但不修改录制关键帧、效果、时间偏移或全局设置。任何局部片段都使用普通可自由定位的画中画，优先于录制 presenter；不因放大人物而强制全屏，也不因隐藏桌面而强制放大人物。

`createCompositionSegment` 冻结起点的小窗实际尺寸、位置、可见性、形状和镜像，不自动居中或放大。普通录制默认保留桌面；所选范围内包含录制 presenter 时默认隐藏桌面，已有局部隐藏／背景则延续原选择，避免新建片段意外显示此前隐去的桌面。录制 presenter 的无形状全屏画面与小窗几何是独立概念，新建普通片段使用保留的小窗布局。`upsertCompositionSegment`／`updateCompositionSegment` 对重叠、非法范围、非有限或越界参数、未知枚举和非法背景引用返回原数组，不覆盖邻段；主进程仍独立校验一帧最短时长和资产所属关系。只有显式 `splitCompositionSegment` 才分割选中段；删除片段后恢复其下方原始时序。所有操作保留源数据及撤销快照。

预览和导出共用 `renderFrame`，先查源时间片段，再独立合成背景、桌面和人物。`tests/composition.test.ts` 覆盖半开区间、源时间裁剪、新建快照、局部更新、拒绝重叠、拆分删除、连续尺寸及边缘钳制、旧项目渲染兼容、presenter 优先级、隐藏与缺失背景不泄漏桌面等行为。

画布的 `Project.style.background` 同样支持工程已注册的 `asset:<id>`，与局部片段共用图片授权、缓存和 `renderFrame`。`shared/backgrounds.ts` 统一优先级：局部隐藏与替换优先，局部保留桌面或段外沿用画布背景。图片按覆盖画布等比居中裁切，透明区域与未加载图片使用中性底色。画布自定义图片工程使用 manifest 11，旧客户端拒绝打开，避免丢失选择。

画布属性的「背景 → 上传图片」复用主进程导入，支持 PNG／JPEG／WebP、20 MB 上限；取消和解码失败不改选择。图片随工程独立保存，手动／自动保存记住最近主动选择的背景；`CanvasBackgroundDefaults` 在用户数据的 `canvas-backgrounds` 中仅保留最近图片和原子写入的 `selection.json`。新录制／导入视频复制图片到自己的工程，移动原图或删除原工程不影响新工程。切回预设清除记忆副本，已有工程图片保留；保存背景未变的旧工程不会覆盖最新默认。可选记忆损坏时新工程使用预设，已有工程仍以自身清单为权威。

## 生产流程验证

构建后运行 `node scripts/verify-composition-editing.mjs --output output/composition-verification-<unique>`。可追加 `--packaged` 验证同版本安装产物的 bootstrap；报告明确记录启动方式，不将 bootstrap 等同于直接启动安装后的 EXE。

验证器只使用独立 profile、项目目录及生成的 7 秒屏幕／摄像头视频和背景图片，不打开物理设备、不发送系统输入、不覆盖用户工程。仅替换文件选择对话框的返回值，项目导入、保存、图片授权和导出均经过生产 IPC 与存储链路。

实际编辑器交互覆盖 2～5 秒局部片段的任意小窗尺寸／位置、桌面保留／隐藏／预设与图片替换、片段移动／修剪／分割／删除／撤销，以及保存后重启恢复。生成 0／3／6 秒预览截图和实际 MP4 解码帧，按合成画面的颜色及人物边界检查段内几何、隐藏／替换时无桌面或鼠标泄漏、段外恢复。另一次导出覆盖全局摄像头关闭但局部显式开启的边界，并校验原始素材哈希不变。结果及失败截图写入指定输出目录；合成像素验证不代替真实摄像头画质审查。
