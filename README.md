# 小录 · SmoRec

![小录：把屏幕、讲解和想法，录成一支视频](docs/readme/hero.png)

小录是一款开源桌面工具，用**语音白板**把说的话变成文字和图形节点，用**自动镜头**放大正在讲解的操作细节。录屏与直播都能缩放聚焦，再配合摄像头、声音和本地剪辑，完成软件教程、流程讲解或产品演示。

[官网与下载](https://smorec.xiaomolian.com/) · [核心亮点](#核心亮点) · [界面演示](#界面演示) · [运行源码](#运行源码) · [开发文档](DEVELOPMENT.md) · [参与贡献](CONTRIBUTING.md)

## 核心亮点

### 语音白板：边讲边把思路画出来

选择“按住说话”，在画布上按住鼠标说话、松开，识别出的文字写入矩形、圆形、菱形或纯文字节点；在已有节点上按住说话，可以原位改字。拖出连线把节点组织成流程图，图形逐笔绘制、文字逐字出现、连线沿路径展开，让讲解内容随着叙述逐步呈现。

语音模型首次下载后在本机识别。白板录制也会根据书写、节点操作和语音按住位置生成聚焦镜头；语音尚未识别出字时，就能持续聚焦正在说的节点。

### 录屏与直播：让观众看清正在操作的地方

点击控件、输入文字或拖选文本时，镜头平滑缩放聚焦到操作区域，停顿后回到全景。**录屏镜头可以后期调整，直播镜头实时响应操作**，合成画面可直接推流或交给直播伴侣。

直播缩放改变观众看到的输出画面，操作者继续使用原始桌面比例；随时可以关闭自动缩放或手动回到全景。录后镜头可利用完整时间轴提前进入，直播只响应已经发生的操作，因此两者的时序有所区别。

## 能做什么

| 你要做的事 | 小录提供的能力 |
| --- | --- |
| 录一段操作 | 选择整个屏幕、单个窗口或框选区域，分别控制麦克风和系统声 |
| 边操作边讲解 | 摄像头浮窗、人物画面布局、提词器与声音效果 |
| 边说边画出思路 | 按住说话生成或修改文字/图形节点，连接成流程图，配合逐笔与逐字呈现；也支持手写、图片、纯画布和完整界面 |
| 让观众看清细节 | 录屏与直播都支持点击、输入和选中文字的缩放聚焦；白板录制也支持动作与语音按住聚焦，录后镜头可手动调整 |
| 把录制变成成片 | 时间轴分割、裁剪、删除片段，调整画布比例、背景、圆角和人物布局 |
| 带着镜头效果直播 | 实时缩放聚焦与人物画面一起合成，经RTMP/RTMPS推流，或通过虚拟摄像头交给直播伴侣 |
| 保留自己的素材 | 工程与原始媒体保存在本机，编辑视频不需要先上传到云端 |

适合软件教程、操作演示、课程讲解、产品介绍，以及需要同时展示屏幕和人物的直播。摄像头、语音模型和直播配置可以按场景选用。

## 界面演示

以下截图来自0.9.118公开源码的真实界面组件，使用合成工程与模拟设备数据；它们展示界面和操作结构，不代表真实设备录制或直播平台验收。封面与示例讲解内容由ImageGen生成，来源见[图片说明](docs/readme/README.md)。

### 1. 先选好录什么

选择屏幕、窗口或区域，在同一条操作栏里控制摄像头、麦克风、系统声和白板。

![录制准备：范围选择、声音控制和开始录制](docs/readme/recorder.jpg)

### 2. 用语音白板把思路展开

用“按住说话”生成带文字的节点，再拖出连线组织思路；也可以手写、输入文字和放入图片。录制时，白板操作和语音按住位置参与镜头聚焦；按场景选择只呈现画布，或保留完整白板界面。下图展示白板布局，语音工具位于底部操作栏。

![白板界面：讲解内容、画布视角和书写工具](docs/readme/whiteboard.jpg)

### 3. 录完直接进入编辑器

在时间轴里剪掉多余片段、调整自动缩放镜头，再设置画布和导出。也可以导入已有视频继续编辑。直播则在操作发生时直接合成镜头效果，无须先录完再剪。

![编辑器：本地项目、画面预览、镜头时间轴和画布属性](docs/readme/editor.jpg)

## 开始使用

**直接使用桌面版**：前往[小录官网](https://smorec.xiaomolian.com/)下载对应平台的安装器。本仓库当前提供客户端源码，尚未发布GitHub二进制Release。

1. 选择录制范围，按需要开启摄像头、麦克风和系统声；使用自动镜头时开启“操作记录”，完成对应系统权限授权。
2. 开始录制，用屏幕操作、语音白板或人物画面完成讲解；首次使用语音白板时，按界面提示下载本机语音模型。
3. 点击“停止并编辑”，在时间轴调整片段、画布与镜头。
4. 导出视频；原始素材继续保留，之后可以重开工程再编辑。

直播时，先配置推流地址或虚拟摄像头输出，开启“操作记录”并完成授权，在本机预览中检查画面、声音与自动缩放，再开始对外输出。自动缩放可以切换为“保持全景”，也可以用“回到全景”快捷键临时恢复完整画面。具体平台接入、系统签名及授权条件见[开发与构建](DEVELOPMENT.md)。

## 运行源码

需要 **Node.js 22.22+、npm 10+**。使用锁文件安装依赖：

```sh
git clone https://github.com/haoqiguai-dizao/smorec-client.git
cd smorec-client
npm ci
npm run dev:web
```

`dev:web`用于阅读和开发界面；录屏、桌面导出、设备权限与虚拟摄像头需要桌面和原生组件。完整桌面开发、Mac/Windows构建与打包步骤见[DEVELOPMENT.md](DEVELOPMENT.md)。

```sh
npm run lint
npm run typecheck
npm test
npm run build
```

### 平台状态

| 平台 | 原生支持与验证范围 |
| --- | --- |
| macOS 15+ · Apple Silicon | 原生支持目标；本次源码在macOS 27 arm64完成独立构建与Mac本地包检查，macOS 15实机尚未验证 |
| Windows · x64 | 包含采集、语音、更新与虚拟摄像头源码；此公开快照尚未完成新Windows环境的原生/NSIS构建验收 |
| Intel Mac / Linux | 没有完整原生录制支持，网页界面能运行不代表桌面链路兼容 |

当前快照基于 **0.9.118**。实际检查、平台限制与未验证场景见[VERIFICATION.md](VERIFICATION.md)；已知依赖告警与安全反馈见[SECURITY.md](SECURITY.md)。
